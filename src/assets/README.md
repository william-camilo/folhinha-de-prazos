# Cenário da mesa

`desk-background.webp` é um cenário estático de 1200 × 800 pixels (20.476 bytes). Os calendários, datas e animações são componentes HTML/CSS independentes da imagem.

A imagem foi criada com a ferramenta nativa imagegen e convertida para WebP com qualidade 78. Não utiliza API ou credenciais de outro provedor.

Prompt da geração:

> Generate a photorealistic website background asset, landscape 3:2. Premium calm home office vignette. EMPTY light warm oak desktop in foreground bottom 32 percent, warm ivory wall in background, softly blurred small olive green plant in a cream ceramic pot on far upper left edge, very subtle softly blurred slim pen holder on far right edge. Wide EMPTY central and right-middle area reserved for a separately rendered interactive desk calendar: do NOT draw any calendar, clock, paper, text, numbers, typography or logo. Eye level slightly above desk, natural warm daylight entering from upper left, extremely restrained styling and neutral warm colors, soft shallow depth of field on props, desk relatively sharp, subtle fine wood grain. The final image is used behind dynamic CSS 3D objects, so center must remain spacious and uncluttered. No dramatic shadows, no giant plant, no vignetting, no watermark.
